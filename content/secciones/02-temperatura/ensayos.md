# Ensayos — Temperatura

## 1. Criterios de aceptación

El resultado se compara con el límite de la especificación del proyecto. La **ASTM C1064 no fija el límite**; solo define cómo medir. Ejemplos de límites habituales (verifica siempre el proyecto):

| Condición | Límite típico de proyecto |
| --- | --- |
| Concreto masivo | Temperatura máxima definida por estudio térmico |
| Clima cálido | ≤ 32 °C (90 °F) al colocar, salvo especificación distinta |
| Clima frío | ≥ 10 °C (50 °F) al colocar, salvo especificación distinta |
| Concreto con hielo o agua enfriada | Verificar mezcla y temperatura de entrega |

## 2. Ejemplo de registro y decisión

| Dato | Valor |
| --- | --- |
| Temperatura medida | 33.0 °C |
| Límite del proyecto | 32.0 °C |
| Hora | 14:40 |
| Condición | Soleado, 36 °C ambiente |
| Decisión | **No conforme**: notificar al supervisor y al productor |

El técnico no “corrige” la temperatura agregando agua ni midiendo en otro punto. Registra el valor real y comunica la desviación.

## 3. Errores que invalidan la lectura

- Sensor con menos de 75 mm de inmersión.
- Cobertura de concreto menor que 3 veces el NMAS.
- Lectura antes de 2 min o después de 5 min.
- Termómetro retirado antes de leer.
- Instrumento sin verificación o con diferencia mayor de 0.5 °C.
- Medición en concreto que ya fue usado para otro ensayo y perdió representatividad.

## 4. Efecto de la temperatura en los demás ensayos

| Fenómeno | Consecuencia |
| --- | --- |
| Temperatura alta | Acelera la hidratación, aumenta la pérdida de slump y puede reducir la resistencia final |
| Temperatura baja | Retrasa el fraguado y el desarrollo de resistencia; riesgo de congelamiento |
| Cambio brusco | Favorece fisuración plástica y térmica |
| Aire incorporado | La temperatura afecta el tamaño y la estabilidad de las burbujas |

Por eso la temperatura se registra junto con el slump y el aire, y se reporta en el informe de los especímenes.
